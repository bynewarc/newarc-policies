Privacy Policy

Fusion BIP SQL Formatter - Browser Extension

Last Updated: January 2026

Overview

Fusion BIP SQL Formatter ("the Extension") is a browser extension developed by Newarc Consulting Inc. that provides SQL formatting capabilities for Oracle Fusion BI Publisher. We are committed to protecting your privacy and being transparent about our data practices.

Key Point: This extension does NOT collect, store, transmit, or share any user data. All SQL processing happens entirely within your browser.

Data Collection

The Extension does not collect any of the following:

  • Personal information (name, email, etc.)
  • SQL queries or code you format
  • Browsing history or website data
  • Usage statistics or analytics
  • Cookies or tracking identifiers
  • Any other form of user data

Data Storage

The Extension uses Chrome's local session storage solely to preserve your SQL content within the current browser tab. This data:

  • Is stored only in your browser's local memory
  • Is automatically cleared when you close the tab
  • Never leaves your device
  • Is never transmitted to any server

Data Processing

All SQL formatting and syntax highlighting is performed entirely client-side within your browser. No data is ever sent to external servers, APIs, or third-party services.

Permissions

The Extension requires the following browser permissions:

  • sidePanel: To display the SQL formatting interface in the browser side panel
  • activeTab: To identify the current tab for state management
  • tabs: To manage tab-specific SQL content
  • storage: To temporarily store SQL content in session storage
  • clipboardWrite: To enable the "Copy to Clipboard" feature
  • host_permissions (*.oraclecloud.com): To enable the extension on Oracle Fusion pages

These permissions are used exclusively for the Extension's core functionality and not for data collection purposes.

Third-Party Services

The Extension does not integrate with, connect to, or transmit data to any third-party services, analytics platforms, or external servers.

Security

Since no data is collected or transmitted, there is minimal security risk associated with using this Extension. Your SQL code remains entirely within your browser at all times.

Children's Privacy

The Extension does not collect any information from anyone, including children under the age of 13.
