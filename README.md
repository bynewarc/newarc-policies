# Oracle BI Publisher SQL Enhancer

Browser extension to transform the Oracle BI Publisher SQL editor into a professional environment.

## Features (v1.0.0)

*   **Syntax Highlighting:** Oracle SQL support.
*   **Formatting:** Auto-format SQL (Ctrl+Shift+F logic available in toolbar).
*   **Export:** Save query as `.sql` file.

## Development

*   Run `npm run dev` to start the development server (for UI testing).
    *   *Note: Chrome APIs like `chrome.downloads` won't work in standard browser mode, but fallbacks are included.*
